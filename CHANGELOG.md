# Changelog

## 1.0.0 — Initial public release

- Added the accepted G2 grave-decoration reward model for 41 active designs.
- Added finite per-design red mastery and blue mastery from Stone gravestones onward.
- Added shared mastery across equivalent workstation variants of the same decoration.
- Rebalanced blue rewards for 23 existing one-time Study recipes without changing Faith/Science costs or non-blue Study outputs.
- Added save-native mastery persistence and cross-save reprojection.
- Preserved ordinary worker/zombie behavior and supported Soul Gratitude's native tech-point-awarding path.
- Added fail-closed guards for host/mod reward mismatches.
- Removed acceptance-only per-craft mastery logging before public release.
