# Better Grave Crafting Rewards

Make better grave decorations worth learning instead of farming the same cheap recipe forever.

Better Grave Crafting Rewards rebalances technology-point rewards from gravestones, fences, crosses, sculptures and other grave decorations. Each design has a finite mastery pool: the first crafts are the most educational, the reward steps down after every two completed items, and eventually that design stops giving manufacturing technology points.

More advanced designs start higher, so normal graveyard progression is rewarded better than repetitive low-tier grinding.

## What changes

- Red mastery for 41 active grave-decoration designs.
- Blue manufacturing mastery from Stone gravestones onward.
- Grave plate and Simple gravestones keep 0 manufacturing blue; Study remains their knowledge route.
- 23 existing grave-decoration Study rewards are rebalanced while staying one-time.
- Equivalent workstation variants of the same decoration share one mastery counter.
- Existing saves are supported and receive the full mastery pool for designs that have no prior BGCR counter.
- Mastery is stored in the normal save; there is no separate mod save file.

The mod does **not** change recipe materials, craft energy/time, grave quality, green rewards, physical decoration output, or unrelated crafting.

Normal zombie/worker crafting does not consume player mastery. Soul Gratitude crafting does when Graveyard Keeper's native path awards those technology points to the player.

## Installation

Requires BepInEx 5.

Place `BetterGraveCraftingRewards.dll` in:

`Graveyard Keeper/BepInEx/plugins`

The research-only BGCR Test Console is not part of the release and is not needed for normal play.

## Compatibility

Tested on Graveyard Keeper 1.407 (Steam, Windows) with all DLC installed.
Other game versions, storefront builds, operating systems, and DLC configurations are currently untested.
