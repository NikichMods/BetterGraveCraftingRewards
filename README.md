# Better Grave Crafting Rewards

A planned Graveyard Keeper 1.407 mod that rebalances technology-point rewards from crafting grave decorations.

The project is currently in the research/design phase. The goal is to make progression through more advanced grave decorations more meaningful and reduce incentives for repetitive low-tier technology-point farming without simply inflating blue-point income.

Current research: [docs/VANILLA_BALANCE_RESEARCH.md](docs/VANILLA_BALANCE_RESEARCH.md)

Shared Graveyard Keeper research: `NikichMods/GraveyardKeeperResearch`.
